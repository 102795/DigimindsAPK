# SiteScan — eerste versie

Zet deze bestanden samen in één map en laat de map `img` met het logo daarin staan:

- `index.html` — de structuur van de pagina.
- `style.css` — de vormgeving.
- `script.js` — de browserlogica en de aanbevelingen.
- `server.js` — de lokale Node.js-server en HTML-analyse.
- `img/logo.jpg` — het logo bovenaan de pagina.

Installeer eerst Node.js (versie 18 of hoger) van https://nodejs.org en controleer met `node -v`.

Start de server met `node server.js` vanuit deze map. Open daarna `http://127.0.0.1:8000` in je browser. Laat het terminalvenster open zolang je de tool gebruikt. Geen API-sleutels of extra pakketten nodig.
