# SiteScan — eerste versie

Zet deze vier bestanden samen in één map:

- `index.html` — de structuur van de pagina.
- `style.css` — de vormgeving.
- `script.js` — de browserlogica en de aanbevelingen.
- `app.py` — de lokale Python-server en HTML-analyse.

Op Windows start je `app.py` met `py app.py` vanuit deze map. Open daarna `http://127.0.0.1:8000` in je browser. Laat het terminalvenster open zolang je de tool gebruikt. Geen API-sleutels of extra Python-pakketten nodig.
